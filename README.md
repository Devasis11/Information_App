# Information & Authentication App

## Overview
This application is designed to securely store and manage user information with an integrated authentication
system. It allows users to register, log in, and access stored data through a protected interface.
The app supports multiple languages to improve accessibility for users from different linguistic backgrounds.

## Language Support
The application provides multilingual support. When the app starts, users are presented with 
a **language selection screen in the first activity** where they can choose their preferred language.

Supported languages:
- English
- Hindi
- Odia

After selecting a language, the application interface loads in the chosen language.

## Features
- Multilingual interface (English, Hindi, Odia)
- Language selection screen at startup
- User registration system
- Secure login authentication
- Structured storage of user information
- Simple and user-friendly interface

## Purpose
The project demonstrates the implementation of:
- User authentication
- Secure information storage
- Multi-language support

It can be used as a base structure for applications that require login systems and multilingual user interfaces.

## Technologies Used
- Android Studio
- Kotlin / Java
- XML Layouts
